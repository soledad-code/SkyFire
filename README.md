# SKYFIRE - Jogo Python com pygame

## INSTRUÇÕES DE EXECUÇÃO

### REQUISITOS

### PASSOS PARA RODAR

1. Extraia o arquivo ZIP
2. Abra o Terminal na pasta do projeto
3. Instale as dependências:
   pip install -r requirements.txt
4. Execute o jogo:
   python main.py

### CONTROLES
 - Player 1:
   Tiro: RCRTL
   Movimento: Setas
 - Player 2:
   Tiro: LCRTL
   Movimento WASD
